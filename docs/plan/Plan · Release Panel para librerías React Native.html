Plan técnico · v1 · 2026-11-19

Release Panel para librerías React Native

Una aplicación web interna en Node.js que versiona librerías alojadas en Bitbucket, empuja el tag que dispara Jenkins (externo), confirma la publicación en Artifactory y actualiza el wrapper brownfield con un PR.

4pantallas en el diseño
9pasos por release
5scripts en package.json
11tareas para Copilot
Instrucciones para Copilot. Respeta las restricciones (§2): sin Vite, sin Yarn. Toda acción sobre un repo pasa SOLO por scripts de package.json (§5). Jenkins es externo: no se invoca ni se configura. Implementa en el orden del roadmap (§13). No inventes URLs ni nombres reales: usa variables de entorno y los placeholders [ARTIFACTORY_URL], [WORKSPACE], @org/. Lo marcado CONFIRMAR es un supuesto.
01 · Contexto

Contexto y objetivo

Varias librerías React Native viven cada una en su repo de Bitbucket y se publican como paquetes npm en Artifactory. Un repo adicional, el wrapper, las consume y empaqueta React Native como librería nativa para apps host existentes (patrón brownfield de Callstack).

1 · Observar

Versión en main, última en Artifactory, la que usa el wrapper y changesets pendientes.

2 · Versionar

Changesets → commit → tag → push. El tag dispara Jenkins.

3 · Confirmar

Polling hasta que la versión exista en Artifactory.

4 · Integrar

Rama en el wrapper con dependencias nuevas y PR en Bitbucket.

Analogía:el panel es la torre de control. No pilotea el avión (Jenkins) ni construye la pista (Artifactory): autoriza el despegue (tag), mira el radar (polling) y coordina el aterrizaje en el aeropuerto destino (wrapper).

// server/src/lib/detect-pm.mjs
import { existsSync } from 'node:fs';
import { join } from 'node:path';

export function detectPackageManager(repoDir) {
  if (existsSync(join(repoDir, 'pnpm-lock.yaml'))) return 'pnpm';
  if (existsSync(join(repoDir, 'package-lock.json'))) return 'npm';
  throw new Error(`Sin lockfile reconocido en ${repoDir}`);
}

export const installCmd = (pm) =>
  pm === 'pnpm' ? ['pnpm', ['install', '--frozen-lockfile']] : ['npm', ['ci']];

// Windows: npm/pnpm son .cmd
export const bin = (name) => (process.platform === 'win32' ? `${name}.cmd` : name);
03 · Arquitectura

Arquitectura

El servidor trabaja siempre en clones temporales (/tmp/release-panel/<jobId>/<repo>), nunca en la copia de trabajo del desarrollador. Un lock por repo impide dos releases simultáneos de la misma librería.

05 · Contrato

Contrato de scripts por librería

El panel solo ejecuta <pm> run <script>. Cada repo puede cambiar cómo implementa un script sin tocar el panel: es inversión de dependencias aplicada a la CI. Haz clic en un script para resaltarlo en el package.json.

import { execFile } from 'node:child_process';
import { promisify } from 'node:util';
const run = promisify(execFile);

export async function latestVersion(pkg, registry) {
  const { stdout } = await run('npm', ['view', pkg, 'dist-tags', '--json', '--registry', registry]);
  return JSON.parse(stdout).latest ?? null;
}

export async function versionExists(pkg, version, registry) {
  try {
    const { stdout } = await run('npm', ['view', `${pkg}@${version}`, 'version', '--registry', registry]);
    return stdout.trim() === version;
  } catch { return false; }   // E404 = aún no publicada
}

export async function waitForVersion(pkg, version, registry,
  { intervalMs = 30000, attempts = 40, onTick } = {}) {
  for (let i = 1; i <= attempts; i++) {
    onTick?.(i, attempts);
    if (await versionExists(pkg, version, registry)) return true;
    await new Promise((r) => setTimeout(r, intervalMs));
  }
  return false; // timeout → estado "Revisar Jenkins"
}

    Scripts de release

    #!/usr/bin/env node
// Crea commit de release + tag anotado y hace push. El tag dispara Jenkins.
import { execFileSync } from 'node:child_process';
import { readFileSync } from 'node:fs';

const sh = (cmd, args) => execFileSync(cmd, args, { stdio: 'pipe' }).toString().trim();
const { name, version } = JSON.parse(readFileSync('package.json', 'utf8'));
const tag = `v${version}`;

if (sh('git', ['rev-parse', '--abbrev-ref', 'HEAD']) !== 'main') {
  throw new Error('Solo se publica desde main');
}
if (sh('git', ['ls-remote', '--tags', 'origin', tag])) {
  throw new Error(`El tag ${tag} ya existe en origin`);
}

sh('git', ['add', '-A']);
sh('git', ['commit', '-m', `chore(release): ${name}@${version}`]);
sh('git', ['tag', '-a', tag, '-m', `${name}@${version}`]);
sh('git', ['push', 'origin', 'main', '--follow-tags']);

// Última línea en JSON para que el servidor la parsee
console.log(JSON.stringify({ name, version, tag, commit: sh('git', ['rev-parse', '--short', 'HEAD']) }));

    import { spawn } from 'node:child_process';

const SECRETS = [process.env.ARTIFACTORY_TOKEN, process.env.BB_TOKEN].filter(Boolean);
const mask = (s) => SECRETS.reduce((acc, t) => acc.split(t).join('***'), s);

export function run(cmd, args, { cwd, onLine }) {
  return new Promise((resolve, reject) => {
    onLine?.(`$ ${cmd} ${args.join(' ')}`);
    const p = spawn(cmd, args, { cwd, env: process.env, shell: false });
    let last = '';
    const handle = (buf) => buf.toString().split('\n').filter(Boolean)
      .forEach((l) => { last = l; onLine?.(mask(l)); });
    p.stdout.on('data', handle);
    p.stderr.on('data', handle);
    p.on('close', (code) => (code === 0 ? resolve(last) : reject(new Error(`${cmd} salió con ${code}`))));
  });
}

// Uso: node scripts/sync-wrapper.mjs @org/rn-auth@5.2.0 @org/rn-analytics@1.9.2
import { execFileSync } from 'node:child_process';
import { existsSync } from 'node:fs';

const sh = (c, a) => execFileSync(c, a, { stdio: 'inherit' });
const pm = existsSync('pnpm-lock.yaml') ? 'pnpm' : 'npm';
const specs = process.argv.slice(2);
if (!specs.length) throw new Error('Indica paquetes pkg@version');

const range = (spec) => {
  const at = spec.lastIndexOf('@');
  const name = spec.slice(0, at), v = spec.slice(at + 1);
  return `${name}@${v.startsWith('0.') ? '~' : '^'}${v}`;
};

const branch = `release/libs-${new Date().toISOString().slice(0, 10)}`;
sh('git', ['checkout', '-b', branch]);
const args = specs.map(range);
pm === 'pnpm' ? sh('pnpm', ['add', ...args]) : sh('npm', ['install', ...args]);
sh('git', ['add', 'package.json', pm === 'pnpm' ? 'pnpm-lock.yaml' : 'package-lock.json']);
sh('git', ['commit', '-m', `chore(deps): ${specs.join(', ')}`]);
sh('git', ['push', '-u', 'origin', branch]);
console.log(JSON.stringify({ branch, specs }));

    type PackageManager = 'pnpm' | 'npm';
type Bump = 'patch' | 'minor' | 'major';
type LibStatus = 'up-to-date' | 'pending-publish' | 'wrapper-outdated' | 'major-review';

interface LibraryState {
  name: string; repo: string; pm: PackageManager;
  repoVersion: string; published: string | null; wrapperVersion: string | null;
  pendingChangesets: number; suggestedBump: Bump | null; status: LibStatus;
}

type StepKey = 'clone' | 'preflight' | 'install' | 'bump' | 'verify' | 'tag'
             | 'jenkins' | 'artifactory' | 'wrapper';
type StepState = 'pending' | 'running' | 'done' | 'failed' | 'external' | 'timeout';

interface Job {
  id: string;                 // REL-YYYY.MM.DD-NN
  items: { name: string; from: string; to: string; bump: Bump }[];
  steps: { key: StepKey; state: StepState; startedAt?: string; endedAt?: string }[];
  createdBy: string; createdAt: string;
  result?: { tag?: string; commit?: string; prUrl?: string };
}

type JobEvent =               // SSE
  | { type: 'log'; line: string; ts: string }
  | { type: 'step'; key: StepKey; state: StepState }
  | { type: 'done'; result: Job['result'] };

    12 · Robustez

    Errores, idempotencia y seguridad

    Punto de no retorno

    El push del tag. Antes se aborta sin efectos; después, nunca se borran tags automáticamente.

    Idempotencia

    Si el tag existe y la versión ya está en Artifactory, el job salta directo al wrapper.

    Lock por repo

    Dos jobs sobre la misma librería → 409 Conflict.

    Timeout

    20 min de polling → estado timeout «Revisar Jenkins» con enlace de solo lectura.

    Secretos

    ARTIFACTORY_TOKEN y BB_TOKEN solo en env, enmascarados en logs, nunca al frontend.

    Comandos seguros

    spawn con argumentos en arreglo y shell:false; paquetes validados contra libraries.config.json.

    Auditoría

    Cada job guarda quién lo lanzó y el log completo (JSONL por job).
